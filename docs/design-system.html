01 / FOUNDATIONS

Cinco principios de diseño técnico.

Antes de cualquier componente, las reglas que rigen cómo se ven y se sienten todas las superficies Slowcraft.

i.

Editorial sobre decorativo.

Cada pieza se piensa como una página de revista de arquitectura. Las palabras importan más que los gráficos.

ii.

Whitespace activo.

El espacio respira y comunica. Nunca llenamos por miedo al vacío. El blanco es contenido, no ausencia.

iii.

Líneas finas y deliberadas.

1px en verde salvia para divisiones. Nunca cajas pesadas, nunca bordes gruesos. La estructura se sugiere, no se grita.

iv.

Tipografía como protagonista.

Una serif y una sans. Nunca tres familias. Máximo dos pesos por página. La jerarquía es por tamaño, no por color.

v.

Acentos raros, nunca constantes.

El cobre es excepcional, no recurrente. Como un sello editorial: un punto, una línea, una cita. Si está en todos lados, no acentúa nada.

Reglas tipográficas

Las cinco reglas inviolables

— Una serif y una sans. Nunca tres familias en la misma página.

— Máximo dos pesos por página (regular 400 + medium 500).

— Letterspacing apretado (-1 a -3) en serif display. Nunca expandido.

— Letterspacing amplio (+2 a +4) en mayúsculas para etiquetas y eyebrows.

— Cursivas solo en serif, para citas o énfasis editorial. Nunca en sans.

12 / MOTION

Movimiento deliberado.

Easings y duraciones. Slowcraft no es lento, pero tampoco es brusco. El movimiento se siente intencional.

Easings

--ease-out · default
--ease-editorial · fades

Duraciones

--duration-fast · 200ms
Hover de botones, links, micro-feedback
--duration-default · 300ms
Transitions estándar, cards, inputs
--duration-slow · 500ms
Cambios de sección, modal entrances
--duration-slower · 800ms
Page transitions, fade-ins de scroll
--duration-deliberate · 1000ms
Hero animations al cargar (uso especial)

Reglas de motion

— Toda transición usa ease-out por defecto. Nunca linear excepto para loops.

— Hover de botones: 300ms. Translate-Y -2px + cambio de color.

— Fade-in de scroll: 800ms con delay escalonado de 200ms entre elementos.

— Si usuario tiene prefers-reduced-motion, todas las duraciones se reducen al mínimo.

14 / APPLY · CÓMO INTEGRAR

Cómo usar el sistema.

Tres formas de integrar Slowcraft Design System a cualquier proyecto, en orden de fricción creciente.

Opción 1 — Importar el CSS de tokens

La forma más rápida. Importa el archivo y todas las variables CSS quedan disponibles globalmente.

@import url('slowcraft_tokens.css');
// O en HTML:
<link rel="stylesheet" href="slowcraft_tokens.css">

Opción 2 — Copiar componentes específicos

Si necesitas solo un botón, una card, o un patrón específico, cópialo directo de este documento. Cada bloque tiene el código mostrado al lado.

Opción 3 — Convertir a librería de componentes (futuro)

Cuando el proyecto crezca, los componentes se pueden empaquetar como librería de React/Vue. Esto se hace cuando hay 3+ proyectos consumiendo el sistema, no antes (over-engineering temprano).

15 · SERVICE ARCHITECTURE

Strategy + Programs.
La doble capa.

Slowcraft ofrece dos capas de servicios claramente diferenciadas. Toda comunicación externa (landing, propuestas, decks de venta) debe respetar esta separación. Es un principio de arquitectura del sistema, no un detalle de copy.

CAPA A · STRATEGY

Engagements de arquitectura

Para empresas que quieren repensar cómo trabajan con IA. Proyectos largos, transformacionales, alcance abierto. Tres servicios: AI Readiness · Workflow Architecture · Implementation Partner.

CAPA B · PROGRAMS

Productos modulares con objetivos específicos

Aplicaciones modulares de la tesis Slowcraft, cada una con un objetivo específico. Los módulos se activan según la madurez del cliente. Cuatro Programs: Founder OS · Site Performance Lab · Conversion Architecture · Studio Automation.

Cuándo usar cuál en comunicación

Strategy primero
En materiales hacia empresas medianas/grandes con presupuesto de transformación, conversaciones de C-level, propuestas a partir de cierto monto
Programs primero
En materiales hacia founders, startups, agencias, dolores específicos puntuales, leads que llegan por tema concreto (sitio lento, automatización, etc.)
Ambos visibles
Landing principal, deck institucional, presentaciones generales

Frase puente canónica

"Strategy es para repensar cómo trabaja tu organización con IA. Los Programs son productos modulares con objetivos específicos, construidos sobre esa misma tesis."

16 · COMPONENT · PROGRAM CARD

El componente que vende un Program.

Anatomía estándar para presentar cualquier Program de Slowcraft, sea en landing, propuesta, redes sociales o deck. Garantiza consistencia y permite que el cliente compare entre Programs sin esfuerzo cognitivo.

Anatomía

01 · Numeración
Número del Program (01-04) en serif grande, color salvia. Marca jerarquía visual sin gritar.
02 · Tag de categoría
FOUNDATIONS · GROWTH · OPERATIONS — letras pequeñas, tracking 2.5px, color cobre. Permite agrupar visualmente.
03 · Nombre
Newsreader serif 36-44px, peso 400, letter-spacing negativo. El nombre es el héroe.
04 · Pitch line
Frase de gancho en serif italic, color cobre, con border-left de 2px. Ver sección 17.
05 · Para quién
Bloque etiquetado con label tracking 2.5px, descripción corta en sans 13-14px. Comunica targeting positivo, nunca exclusión.
06 · Lista de módulos
Lista vertical con divisores horizontales sutiles. 4-8 ítems máximo. Cada módulo se entiende solo.
07 · Nota de modularidad
Frase final en gris/itálica que aclara: "módulos activados según madurez del cliente". Comunica flexibilidad sin perder profesionalismo.

17 · PATTERN · PITCH LINE

El gancho en una línea.

Cada Program (y cada engagement de Strategy en el futuro) tiene una pitch line — una sola frase italiana en serif, color cobre, con border-left. Es el hook emocional que el cliente recuerda incluso si no lee el resto.

Las cuatro pitch lines canónicas

FOUNDER OS

El sistema operativo de tu startup, diseñado desde el día uno con IA adentro.

SITE PERFORMANCE LAB

Cada segundo que tarda tu sitio, pierdes una conversión.

CONVERSION ARCHITECTURE

Si te encuentran pero tu sitio no convierte, no funciona.

STUDIO AUTOMATION

Produces mucho y rentabilizas poco. Automatiza la operación.

Reglas para escribir una pitch line

Longitud
Entre 8 y 16 palabras. Si necesita más, no es pitch — es párrafo.
Estructura
Diagnóstico + consecuencia, o problema + solución. Nunca lista de features.
Tono
Directo, casi confrontativo. La marca se permite tutear al cliente con respeto.
No hacer
Adjetivos genéricos ("la mejor solución") · jerga técnica · promesas exageradas · superlativos vacíos
